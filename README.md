# 構造写像実験パック v0.1

個人の構造写像行動を探索する、ローカル実行用プロトタイプです。
診断や能力評価を目的とせず、課題間の違いや回答過程を観察します。

## 収録課題

- 関係対応
- 表面類似性と構造類似性
- 構造再構成

各課題を2試行ずつ実行します。操作イベント、最終回答、所要時間、
確信度を共通形式でSQLiteへ保存します。

## 動かし方

Python 3.11以降で次を実行してください。外部パッケージは不要です。

```powershell
python app.py
```

ブラウザで <http://127.0.0.1:8000> を開きます。

データは初回実行時に次へ保存されます。

```text
data/structure_mapping.sqlite3
```

終了画面の「JSONログを保存」から、セッション単位の生ログを出力できます。

## テスト

```powershell
python -m unittest discover -s tests -v
```

## データ構造

- `sessions`: 参加者IDと実験開始・終了
- `trials`: 提示条件、回答、得点、時間、確信度
- `events`: 選択、対応作成、変更、解除などの時系列ログ

問題文と分析指標は探索用の暫定版です。研究的妥当性や標準化された
認知能力スコアを提供するものではありません。
